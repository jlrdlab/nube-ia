# Fase 0 - Preparar el entorno

Objetivo: dejar listo WSL Ubuntu, VS Code, Python 3, Git y la cuenta de GitHub.

## Pendientes
- [x] Instalar WSL con Ubuntu (Ubuntu 26.04.1 LTS sobre WSL 2)
- [x] Instalar Python 3 y Git dentro de WSL (Python 3.14.4, pip 25.1.1, venv, Git 2.53.0)
- [x] Configurar nombre y correo de Git (correo privado noreply de GitHub)
- [ ] Crear el repositorio nube-ia en GitHub y subir esta carpeta
- [ ] Curso GitHub Skills: Introduction to GitHub

## Notas
- Trabajar los proyectos dentro de Linux (`~/nube-ia`), no en `/mnt/c`.
- Usar siempre `git` y `python3` de Linux, no los `.exe` de Windows.
- `systemd-binfmt.service` falla al instalar paquetes en WSL: es conocido y no afecta.
